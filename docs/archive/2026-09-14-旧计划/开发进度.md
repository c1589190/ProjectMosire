## 已知缺口（进 P2-7 剩余任务前须知）

> 这些是**已建成但尚未接线**或**已确认缺失**的项，正是 P2-7 剩余任务（尤其 Task 23）要闭合的范围。

1. **装配缺口（Task 23 主体）**：生产 `App` 仍用 `new BasicContextAssembler()`（空内容源）与 9 参 `AgentPipeline`（`DiscardingConversationStore`）。`MainMosire` 对 `SkillCatalog`/`MemoryRetriever`/`MemoryStore`/`ConversationStore`/`Compactor`/`ContextSources`/`ContextPolicy` 的命中数**全部为 0** —— 技能/记忆/压缩/会话存储**四件套已交付但零生产构造点**。另：`AgentRuntime` 公开的"收装配器"构造器只吃 `AgentConfig`，`AgentSpec` + 自定义装配器的全参构造是 private，装配面需扩。
2. **MCP 路径权限判定缺失**（`AgentToMcpServer.handleCall` 不调 `PermissionChecker`）—— 已确认为真实 enforcement gap：子 Agent 的白名单只在子进程内自我约束，父侧按名取工具即执行。当前无实际提权（危险工具尚未注册），但**必须在 Task 23 注册新工具前闭合**（已拆为 Task 23-C，简报就绪）。
3. **启动时序文档 vs 现实**：`开发计划.md:137` 声称的 `ConfigLoader`/`LogBootstrap`/`SkillCatalog.scan` 在 Java 代码中**零命中**（仅存在于文档）。
4. **配置面**：`ConfigStore` 尚未落地（Task 20）；`keys.*` 解析、`configs/` 根目录决定、`ApiKeySource` 真实实现归 Task 20/23。
5. **评审遗留 Minor**：`AgentSpec` 七个二期字段生产零读者；`finish_reason` 读取；`CompactSummary.parse` 三种失败形态不可辨；`ShellOutputTruncator` 第三退出路径可达性；多行记忆转义等 —— 已登记，随 Task 23/最终评审统一处置。
6. **T19 承载的 T23 前置约束**（评审 M-2）：插件源保留名表当前只含 `builtin`，**工具数为 0 的宿主源可被插件抢注** —— T23 装配时**必须**保证宿主源**先于**插件装载完成注册，或扩展 `RESERVED_SOURCE_IDS`；另 `plugin.lifecycle` 落库判读须按 `PluginListener` Javadoc 的标识退化口径（描述符阶段失败时 pluginId 是 JAR 文件名形态、version 空串，事件流里同串可现）。
