# 二期（P2-1~P2-7）执行计划 —— 任务级拆解

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development 逐任务实现。步骤用 `- [ ]` checkbox 跟踪。
> **Goal:** 把《开发计划-二期.md》七个波次拆为 22 个可独立验收的任务（SDD 风格），每任务含文件/接口/失败测试先行/验收命令。

**Architecture:** 主计划《开发计划.md》（P0，D1–D12 冻结）+ 二期计划《开发计划-二期.md》（D13–D19、波次 P2-1~P2-7、AgentSpec 字段表 §六、Token Economy 横切 §四）。模块边界 D2（Main→Brain→AgentLib 单向）不可违反。

**Tech Stack:** Java 21 / Maven 3.9.16（`./mvnw`）/ jdk.httpserver + 虚拟线程 / SQLite(WAL+FTS5) / 官方 MCP SDK 2.0.1 / A2A SDK 1.3.1.Final / **PF4J 3.15.1** / JUnit 6 + AssertJ。

**Spec:** `开发计划-二期.md`（波次做法/验收为准）+ `开发计划.md` §一 冻结决策 + `AGENTS.md`（仓库约定/红线）。

## Global Constraints

- **D1/D2/D12** 模块单向依赖；AgentLib 无 Agent 假设（不 import brain/main）；Brain 不 import main；包前缀 `io.mosire.agentlib|brain|main`。
- **D3** 核心零 web 框架（jdk.httpserver + 虚拟线程）；不上 Spring/Quarkus/DI；PF4J 是插件框架非 DI，允许（D13）。
- **D9（红线 1）** 权限单调性：spawn/配置变更/ToolSource 启停必须经 `PermissionMonotonicityGuard`。
- **D10（红线 5 + 防跑飞）** 任何工具不能关进程；子 Agent 硬顶从父级派生只能更小；进程树级清理。
- **D13** ToolSource = PF4J `ExtensionPoint`；system extensions（main classpath）+ plugin extensions（`plugins/` 目录）；全局可用 ≠ 单 Agent 可用。
- **D15** FTS5 先行 + `EmbeddingProvider` SPI 预留（无实现桩）；CJK 必须 `trigram` tokenizer。
- **D19** HTTP 调试服务内存态、不持久化；取消为循环级检查点。
- **红线 3/4** MCP 新代码禁用 Roots/Sampling/Logging/legacy HTTP+SSE；信任边界=进程边界（PF4J 插件 JAR 独立 ClassLoader 但同 JVM，只放自审插件）。
- 协议消息 record + sealed interface、穷尽 switch；中文 Javadoc（公开 API）。
- 门禁：`./mvnw -N spotless:apply` 后 `./mvnw verify` 全绿；禁止跳过 SpotBugs（抑制需注释理由）。
- 迭代期内存受限（1.6GB）：单任务验证 `./mvnw -pl <模块> -am test -Dspotbugs.skip=true`；完整 `./mvnw verify` 每波收尾一次。
- 提交信息：中文一句话（沿用仓库风格）。
