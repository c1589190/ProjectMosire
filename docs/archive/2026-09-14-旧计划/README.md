## 为什么归档

三代计划的组织方式在叠加中失效了：
- **P0 计划**（`开发计划.md`）写于动工前，里程碑 M0–M4 与九需求域的实际推进早已分叉（M3 从未按原样启动，被二期 P2-1~P2-7 取代）；

- **三期**又拆成总纲 + 五个小段，其中 S3/S5 的落地状态只反映在 SDD 账本里，计划文件本身**落后于现实**（最典型：`开发计划-三期-第五小段.md` 写着"待开工"，实际 S5-A~E 已全部关账）。
- 于是"读计划文件得到的进度"与"读账本得到的进度"**系统性不一致**——这正是本仓已登记过的缺陷形态（文档自陈 vs 现实），继续叠加只会放大它。
