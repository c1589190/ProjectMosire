# M2 收尾（W2–W5）执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已实现但未接线的模块（MCP 双向、A2A server/client）接入 App 装配层，补齐缺失模块（SubagentManager、Main `agent --id`、AG-UI SSE、AdminREST 扩展、smoke.sh），达成 M2 里程碑总验收。

**Architecture:** 主计划《开发计划.md》（P0）总纲 + 中期计划《开发计划-中期.md》为执行谱系。本计划按 SDD 把中期计划 W 波次拆为 8 个任务（含遗留 R6/R9），逐任务独立可验收。模块边界 D2 不可违反。

**Tech Stack:** Java 21 / Maven 3.9.16（`./mvnw`）/ jdk.httpserver + 虚拟线程 / SQLite(WAL) / 官方 MCP SDK 2.0.1 / A2A SDK 1.3.1.Final / JUnit 6 + AssertJ。

**Spec:** `开发计划-中期.md`（执行谱系，每任务的"做法/关键点/测试/验收"以该文 §二 对应波次为准）+ `开发计划.md` §一 冻结决策 / §四.4 / §五.1–5.2 + `AGENTS.md`（仓库约定）。

## Global Constraints

来自 `开发计划.md` §一 与 `AGENTS.md`，逐条从属每一任务：

- **D1** 模块单向依赖：MainMosire → BrainMosire → AgentLibMosire；Java 21（`--release 21`）。
- **D2/D12** AgentLib 无 Agent 假设、不得 import `io.mosire.brain.*`/`io.mosire.main.*`；Brain 不得 import `io.mosire.main.*`；包前缀 `io.mosire.agentlib|brain|main`。
- **D3** 核心零 web 框架：网关用 jdk.httpserver + 虚拟线程；不上 Spring/Quarkus/DI。
- **D4** 子 Agent = 同 jar stdio 子进程（`java -jar mosire.jar agent --id <id>`），内部以 MCP stdio 暴露。
- **D6** A2A server = 官方 `a2a-java-sdk-spec` + `a2a-java-sdk-jsonrpc-common` 纯模块 + 自写 jdk.httpserver JSON-RPC 绑定；不用 server-common/CDI。
- **D9（红线 1）** 权限单调性：spawn/配置变更必须经 `PermissionMonotonicityGuard`；Agent 不能授予超出自身权限。
- **D10（红线 5 + 防跑飞）** 任何工具不能关进程（进程生命周期归 SubprocessManager/Main 管理）；子 Agent 硬顶（maxTurns=2000 / maxToolCallsPerTurn=30 / timeBudget=10min，可配）从父级派生只能更小；进程树级清理。
- **D11** 中文 Javadoc（公开 API 必须）；测试全离线（FakeLlmClient 脚本化 / `sh -c` echo server / 假子进程脚本）；门禁 Spotless(google-java-format)→Checkstyle→SpotBugs→Surefire。
- 协议消息用 record + sealed interface，穷尽 switch。
- 红线 4：信任边界=进程边界；红线 3：MCP 新代码禁用 Roots/Sampling/Logging/legacy HTTP+SSE。
- 红线 3/网络面：网关默认 127.0.0.1。
- 构建：必须用 `./mvnw`（勿用系统 mvn）；改完代码先 `./mvnw -N spotless:apply`。
- 迭代期内存受限（实验机 1.6GB）：单任务验证用 `./mvnw -pl <模块> -am test -Dspotbugs.skip=true`；完整 `./mvnw verify`（SpotBugs 长达 30 分钟窗口）仅在 Task 8 收尾时跑一次。
- 提交信息沿用仓库风格：中文一句话（如 `AgentLib 新增 proc 包：SubprocessManager 子进程管理三件套`）。
- 中期计划 §四：新代码离线可测；每波次 `./mvnw verify` 全绿再进下一波；禁止跳过 SpotBugs 告警（需抑制必须写注释理由）。
