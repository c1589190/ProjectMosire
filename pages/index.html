Mosire Maven 仓库

这是一个只读 Maven 仓库（GitHub Pages），不是网站首页的替代品。

消费方：加一段 repository 就能用

<repositories>
  <repository>
    <id>mosire-pages</id>
    <url>https://c1589190.github.io/ProjectMosire/</url>
    <releases><enabled>true</enabled></releases>
    <snapshots><enabled>false</enabled></snapshots>
  </repository>
</repositories>

<dependency>
  <groupId>io.mosire</groupId>
  <artifactId>docs-mosire</artifactId>
  <version>0.1.0</version>
</dependency>

已发布的制品（0.1.0）

坐标jarsources版本清单
io.mosire:agentlib-mosire jar sources metadata
io.mosire:workspace-mosire jar sources metadata
io.mosire:docs-mosire jar sources metadata
io.mosire:mosire-parent（父 pom，必须一起拿） pom metadata

说明

  • 依赖方向：docs-mosire → workspace-mosire → agentlib-mosire；写两条依赖即可，agentlib 会传递带过来。
  • 只发固定版本（不发 SNAPSHOT）：Pages 上的文件被覆盖就没有可复现性了。
  • 历史版本保留（发布用 keep_files=true），消费方可以钉旧版。
  • 需要 JDK 21。
  • 接入细节（权限面三命名空间、destructiveAllowed、identity.instanceId 即工作区调用者键等）见仓库内 接入指南-三个库给消费方.md。

维护方发新版：git tag -a vX.Y.Z && git push origin vX.Y.Z —— 由 .github/workflows/publish-maven.yml 自动构建并发布到这里。
