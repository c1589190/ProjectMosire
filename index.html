Mosire Maven 仓库

只读 Maven 仓库（GitHub Pages）。当前版本：0.2.2。
发布 io.mosire:agentlib-mosire / workspace-mosire / docs-mosire 三个库 + 父 pom mosire-parent；公开、消费方零认证。

接入

在 pom.xml 里加仓库：

<repositories>
  <repository>
    <id>mosire-pages</id>
    <url>https://c1589190.github.io/ProjectMosire/</url>
    <releases><enabled>true</enabled></releases>
    <snapshots><enabled>false</enabled></snapshots>
  </repository>
</repositories>

按需加依赖（agentlib-mosire 会被后两个传递带出）：

<dependency><groupId>io.mosire</groupId><artifactId>docs-mosire</artifactId><version>0.2.2</version></dependency>
<dependency><groupId>io.mosire</groupId><artifactId>workspace-mosire</artifactId><version>0.2.2</version></dependency>

当前版本制品（0.2.2）

  • io.mosire:agentlib-mosire： jar · sources
  • io.mosire:workspace-mosire： jar · sources
  • io.mosire:docs-mosire： jar · sources
  • io.mosire:mosire-parent（父 pom，子模块靠它解析）： pom

须知

  • 只发固定版本（不发 SNAPSHOT）；需要 JDK 21。
  • 历史版本文件保留（可钉旧版），但 maven-metadata.xml 只反映最近一次发布。
  • 详细接入文档（权限面、工具面、常见坑、已知不兼容）以仓库为准： 对接须知 · 接入指南 · 仓库主页

发版（维护方）

打 tag 即发布：git tag -a vX.Y.Z -m "…" && git push origin vX.Y.Z， 触发 publish-maven 工作流（定版本 → 只发布父 pom + 三个库 → 校验布局 → 推 gh-pages）。 页面里的 0.2.2 由发布版本替换；版本变更说明见对应 tag 的注释。

单文件静态页：无 JS、无外部资源依赖。
