### 3.3 协议栈（用户材料的优先级判断）
```
用户/UI：AG-UI（Agent↔用户/App）、A2UI（Agent→声明式UI）、MCP Apps（Tool→交互UI）、ACP（Editor↔Coding Agent）
Agent Runtime（Hermes/Codex/OpenCode/Goose/...）
A2A（Agent↔Agent）
MCP（Agent↔Tool/Data）
底层：OpenAPI/HTTP/JSON-RPC/gRPC/SSE、OAuth/OIDC/WebSocket
```
- **MCP**：第一优先级。2026-07-28 规范大改（stateless core、MRTR、header routing、cacheable lists、authorization hardening、正式 extensions framework）；Tier-1 SDK 月下载近 5 亿；**有官方 Java SDK（正式 Tier 路线）**。
- **A2A**：**v1.0 已于 2026-03-12 成为稳定 production-ready 版本**；支持 Agent Card/发现、task、artifact、streaming、polling、webhooks、版本协商、多租户、签名 Agent Card、JSON-RPC、HTTP+JSON/REST、gRPC；150+ 组织支持；**官方 Java SDK，三 transport 均有 client+server**。
- **AG-UI**：event-based、双向状态同步；streaming text、tool calls、state sync、client-side tools、HITL、UI intents、agent progress；官方文档称已列有 Java SDK/integrations（需核实）。
- **ACP = Agent Client Protocol**（注意不是 IBM 老 ACP）：Editor/Client↔Coding Agent；JSON-RPC over stdio（本地）、HTTP/WebSocket（远程）；files/diffs/prompt/session/stream update/tool calls/permission request/capability negotiation；**官方 Pure Java SDK**（client+agent、stdio+WebSocket、sync+async、annotation-based agent）。
- **A2UI**：v1.0 仍为 Candidate；JSON-based、streaming、declarative UI；与 AG-UI 可合用。
- **MCP Apps**：2026-01-26 成为第一个正式 MCP Extension 并 production-ready；Tool 返回 HTML/JS UI，客户端 iframe sandbox。
- **Agent Skills**：能力打包标准 `SKILL.md`（yaml frontmatter: name/description）+ scripts/references/assets；渐进式披露（平时只加载 metadata）；应直接兼容。
- **AGENTS.md**：repo 里的 Agent 时代 README（怎么 build/test、风格、禁改清单、约定）；应能理解。
- **UCP / AP2**：Agent 商务/支付，第一阶段不碰，观察。
- **ANP（Agent Network Protocol）**：Agent Internet 愿景（identity/DID/name system/discovery/messaging/E2E/federation/payment），1.1 版但部分 draft，**关注不绑定**。
- **老 ACP（IBM/BeeAI Agent Communication Protocol）**：2025-08-27 已归并进 A2A、仓库归档；新项目禁用。今天说 ACP 默认指 Agent Client Protocol。

### 3.4 用户材料的核心结论（这是本调查最重要的边界判断）
- 协议全部有现成标准，**不要自造**：Agent→Tool 用 MCP；Agent→Agent 用 A2A；Agent→用户 App 用 AG-UI；Editor→Agent 用 ACP；Agent→UI 用 A2UI；Tool→UI 用 MCP Apps；能力打包用 Agent Skills。
- **没有任何主流协议解决的是**："一个人的整个数字世界怎样被统一描述" —— Person/Project/Conversation/Game/Entity/Event/Observation/Claim/Evidence/Thought/Decision/Task/Intent/Relationship/Document/Application/Session/WorldState 之间的关系。
- 因此自研核心 = **Personal Information Model + Universal Event Store + Permission/Identity + Context Construction**，围绕 `MCP / A2A / AG-UI` 三个边界。
- 对 Java 有利：MCP、A2A、ACP 均有正式 Java 路线。
